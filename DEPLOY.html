借月改轨 · 独立托管说明
Borrowed Moon · Independent hosting

这是一份可部署的源代码包，尚未发布到独立服务器。需要你自己的托管账户或服务器；公网域名和 HTTPS 由所选平台提供或配置。换域名或平台不能保证所有国家、地区和网络都能访问。
This is a deployment-ready source package, not an already published independent site. You need a hosting account or server, plus a public address and HTTPS. Availability must be tested on the intended networks; no host or domain guarantees access everywhere.

1. 需要什么 / Requirements

  • 支持常驻 Node.js 24 或 Docker 的服务器，以及一块持久磁盘。仅静态网页托管、临时磁盘的无服务器函数不能直接运行这个完整版本。
    Use a host that runs a persistent Node.js 24 process or Docker container, with persistent disk. Static-only hosting and functions with temporary disk cannot run this full package directly.
  • 完整版本包括单机五关、星图变奏、联机房间和公共排行榜。Node.js 内置 SQLite，无需安装 npm 依赖。
    The package includes the solo campaign, chart variations, online rooms and shared rankings. It uses built-in SQLite; no npm dependencies are needed.
  • 独立站使用自己的数据库，现有 ChatGPT Sites 房间和排行榜不会自动转移。
    This deployment has its own database. Existing ChatGPT Sites rooms and rankings are not transferred automatically.

2. 用 Docker 启动 / Run with Docker

在解压后的项目文件夹执行：
Run these commands in the extracted project folder:

docker build -t borrowed-moon .
docker volume create borrowed-moon-data
docker run -d --name borrowed-moon --restart unless-stopped -p 8080:8080 --mount source=borrowed-moon-data,target=/data borrowed-moon

本机打开 http://localhost:8080。这是本机地址，不能直接发给其他玩家。对外发布时，将平台入口或 HTTPS 反向代理连接到容器的 8080 端口。
Open http://localhost:8080 on the host machine. This local address is not a share link. Connect your hosting platform's public HTTPS endpoint or reverse proxy to container port 8080.

在支持 Docker 的平台：使用本项目的 Dockerfile；容器端口设为 8080；持久磁盘挂载到 /data；实例数设为 1；健康检查路径设为 /healthz。
On a Docker hosting platform: use the supplied Dockerfile, expose port 8080, mount persistent storage at /data, use one instance, and set the health-check path to /healthz.

3. 直接用 Node.js 启动 / Run with Node.js

node --version
node build.mjs
node serve.mjs

Node 版本应为 24 或以上。默认端口 8080，数据库保存在当前目录的 data/borrowed-moon.sqlite。首次启动自动建表，以后启动只执行尚未应用的迁移。
Use Node.js 24 or newer. The default port is 8080 and the database is data/borrowed-moon.sqlite under the current working directory. Startup applies each database migration once.

环境变量 / Variable含义 / Meaning
HOST监听地址，默认 0.0.0.0 / Listen address
PORT监听端口，默认 8080 / Listen port
DB_PATHSQLite 文件位置；Docker 内为 /data/borrowed-moon.sqlite / Persistent database path

4. 保存成绩与更新 / Keep scores and update

  • 房间、排位进度和公开成绩都保存在数据库。必须保留持久磁盘；重建容器时继续挂载同一数据卷。
    Rooms, ranked sessions and public scores live in the database. Keep the persistent disk and reattach the same volume when replacing a container.
  • 同一个数据库只运行一个应用实例。不要把 SQLite 文件放在多台服务器之间共享的网络磁盘上。
    Run one application instance per database. Do not share this SQLite file between servers over a network filesystem.
  • 备份前先停止应用，再复制整个数据目录。不要在应用运行时仅复制一个 .sqlite 文件。数据库包含玩家昵称和房间凭证的哈希，应妥善保存。
    Stop the application before copying the complete data directory for backup. Do not copy only the .sqlite file while the app is running. Protect backups: they contain player nicknames and hashed room credentials.
  • 更新时先备份数据，再换源代码、构建并重启。不要编辑已经执行过的迁移文件；增加新的 SQL 迁移。
    Back up before an update, then rebuild and restart with the same database. Keep applied migration files unchanged and add new migrations for future schema changes.

5. 发给玩家前 / Before sharing

用目标玩家实际使用的网络打开公网 HTTPS 地址，创建房间，让另一台设备加入，完成一关并检查排行榜，再重启服务器确认成绩仍在。独立托管完成前，离线 HTML 只能提供本机单人游戏，不能同步公共排名或联机房间。
Test the public HTTPS URL on your players' actual networks. Create a room, join from a second device, solve a chapter, check the leaderboard, then restart the server and confirm the score persists. The standalone offline HTML supports local solo play; it cannot sync shared rankings or online rooms.

Borrowed Moon / 借月改轨

Five-chapter puzzle campaign, seeded variations, interactive tutorial,
multiplayer rooms and separate solo/team leaderboards.

Node.js 24.22.1. No npm dependencies.
Build: node build.mjs
Start: node serve.mjs

render.yaml is the proposed independent Render deployment:
one Singapore web service with a 1 GB persistent disk.
Applying this Blueprint creates billable resources.
Review the Render plan and current prices before approving.

SQLite data lives at DB_PATH, which must be inside a persistent disk.
Run a single instance. Restarts and deploys must preserve that disk.
This deployment begins with a separate database; prior Sites rooms and
scores do not transfer automatically.

Open DEPLOY.html for additional deployment details.
Availability in Shanghai must be checked after the new URL goes live.
